SOFTWARE

A smart assistant
for the bench.

The computational tools behind BRIDGE turn the SynNotch cascade into something you can query — which knob to turn next, and how many engineered cells a lesion would need.

What It Does

The software packages the BRIDGE model into two usable modules. The pathway simulator reproduces the intracellular cascade — BCAN binding, S2/S3 cleavage, GAL4-VP64 release, 5×UAS transcription, BDNF output — and sweeps its kinetic parameters to find the rate-limiting step. The microenvironment simulator diffuses secreted BDNF through a 3D lesion volume and reports concentration–time profiles at every cell, including healthy neurons that should stay below pharmacologically active levels.

How the Wet Lab Uses It

The loop is deliberately short: sweep candidate designs in silico, rank them by predicted BDNF-per-BCAN, and send only the top candidates to the bench. Wet-lab measurements — reporter curves, ELISA concentrations — flow back to refit the parameters, so the assistant gets sharper every DBTL cycle. This is the model doing practical work: fewer failed transfections, fewer wasted cell preps.

Availability

The code is being documented for release under an OSI-approved open-source license, with the source hosted on the team's dedicated iGEM GitLab repository, so future teams can run, inspect, and extend both simulators. Documentation and release packaging are in progress.

The biology and equations behind both simulators live on the Model page — this page is about the tool; that one is about the science.
